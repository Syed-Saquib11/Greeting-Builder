# Greeting Builder

Roadmap.sh Javascript project: A small JavaScript helper that builds a greeting from a person's name and the time of day.

## Project Link
- https://roadmap.sh/projects/js-greeting-builder

## Functions
- `formatName(firstName, lastName)` – returns the full name as one string
- `getGreeting(timeOfDay)` – returns "Good morning", "Good afternoon" or "Good evening"
- `createGreeting(firstName, lastName, timeOfDay)` – combines both and returns the final greeting

## Example
​```js
console.log(createGreeting('Ava', 'Stone', 'morning'));
// Good morning, Ava Stone
​```

## Run
​```bash
node index.js
​```
